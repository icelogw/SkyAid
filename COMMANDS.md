# SkyAid commands

Every command is client-side: none of them are sent to Hypixel. `/skyaid help`
shows this list in game, with the runnable ones clickable.

## Prices & economy

| Command | What it does |
|---|---|
| `/skyaid price <item>` | Bazaar or auction price, with a 7-day trend line |
| `/skyaid price BZ <item>` / `AH <item>` | Force which market to ask |
| `/skyaid flips` | Best bazaar flip margins right now |
| `/skyaid craft <item>` | Craft cost vs sell price, from real recipes |
| `/skyaid auctions` | Your auctions: top bid, last bid, time left |

## Museum

| Command | What it does |
|---|---|
| `/skyaid museum` | Check your museum: donated count and what's missing |
| `/skyaid museum value` | Cheapest remaining museum XP at live prices |

## Garden

| Command | What it does |
|---|---|
| `/skyaid jacob` | The next Jacob's contests and their crops |
| `/skyaid jacob watch <crop>` | Toggle a crop watch - pings 5 minutes before its contests |
| `/skyaid visitors` | What Garden visitors have cost you, session and lifetime |

## Mouse lock

| Command | What it does |
|---|---|
| `/skyaid mouselock` | Open the preset group menu |
| `/skyaid mouselock on` / `off` | Master switch for the hold-keys |
| `/skyaid mouselock save <1-6>` | Save the current camera angle to a slot |
| `/skyaid mouselock set <yaw> <pitch>` | Glide to an exact angle, hold 3 seconds, release |

## Waypoints

| Command | What it does |
|---|---|
| `/skyaid waypoint` | List your beacon markers |
| `/skyaid waypoint add <name>` | Drop a marker where you stand |
| `/skyaid waypoint remove <name>` | Remove one marker |
| `/skyaid waypoint clear` | Remove every marker |

## Players & chat

| Command | What it does |
|---|---|
| `/skyaid stats <player>` | Level, skill average, coins, networth estimate |
| `/skyaid highlight` | List your custom highlight words |
| `/skyaid highlight add <word>` / `remove <word>` | Manage highlighted words |

## Session & stats

| Command | What it does |
|---|---|
| `/skyaid session` | This session's coin and bit gains |
| `/skyaid session reset` | Start the session counters over |

## Setup & help

| Command | What it does |
|---|---|
| `/skyaid help` | The command list, in game |
| `/skyaid tutorial` | The money-making guide menu (`early`/`mid`/`late` for chat versions) |
| `/skyaid key add` / `status` / `clear` | Manage your Hypixel API key |
| `/skyaid report` | Where to report bugs - Discord and GitHub |
| `/skyaid dump` | Write everything SkyAid can see to a file, for bug reports |

## Keybinds (Options > Controls > SkyAid)

| Key | Default | What it does |
|---|---|---|
| Open the bazaar | F4 | Opens the bazaar for the hovered item |
| Hold for mouse lock 1-6 | unbound | Locks the camera to a preset while held |
| Enable / disable mouse lock | unbound | The master switch, on a key |
| Toggle SkyBlock HUD | unbound | Hide/show the HUD |
| Toggle SkyAid | unbound | The whole mod on/off |
| Open SkyAid settings | unbound | The settings screen |
